# سیستم مدیریت محتوا (CMS)

راهنمای استفاده و توضیح فنی پنل مدیریت سایت. نشانی پنل: `/admin`.

## چه چیزهایی از پنل ویرایش می‌شود

| بخش پنل | چه چیزی | کجای سایت |
| --- | --- | --- |
| **مقالات** | نوشتن، زمان‌بندی، انتشار، کاور، سئو، تاریخچهٔ نسخه‌ها، رونوشت | `/articles`، صفحهٔ هر مقاله، خانه، RSS، نقشهٔ سایت |
| **صفحه‌ها** | صفحه‌های آزاد با متن MDX (مثل «سؤال‌های رایج») | `/<نشانی>` — و `privacy` / `terms` جای متن پیش‌فرض آن صفحه را می‌گیرند |
| **متن‌ها و دکمه‌ها** | هر تیتر، پاراگراف، دکمه، پیوند، عکس، منو، فوتر، کانال‌های تماس، فهرست پروژه‌ها، برچسب‌های فرم تماس، صفحهٔ ۴۰۴ و سئوی هر صفحه | همهٔ صفحه‌های اصلی |
| **رسانه** | بارگذاری تصویر و PDF، متن جایگزین، کپشن | هرجا تصویر انتخاب شود |
| **موضوع‌ها** | دسته‌بندی مقاله‌ها | `/topics` |
| **درخواست‌ها / مشترکین** | پیام‌ها و فرم مشاوره / خبرنامه | — |
| **کاربران و دسترسی** | ساخت حساب، نقش، غیرفعال‌کردن، تعیین گذرواژه | — |
| **گزارش تغییرات** | چه کسی، چه چیزی را، کی عوض کرد | — |

### نوشتار ساده در متن‌های کوتاه

در فیلدهای متنی بخش «متن‌ها و دکمه‌ها» این چند علامت کار می‌کنند:

- `*عبارت*` ← رنگ تأکید (سبز روی زمینهٔ روشن، طلایی روی نوار سبز)
- `**عبارت**` ← پررنگ
- `[متن](/contact)` ← پیوند
- رفتن به خط بعد ← شکست خط
- `{{years:1380}}` ← تعداد سال‌های گذشته از ۱۳۸۰، که هر نوروز خودش به‌روز می‌شود
- `{{year}}` ← سال جاری شمسی

هیچ HTML‌ای از این فیلدها رندر نمی‌شود.

### دکمه‌ها و پیوندها

هر دکمه دو بخش دارد: **متن** و **مقصد**. دکمه‌ای که متنش خالی باشد روی سایت نمایش داده نمی‌شود.
مقصد باید با `/` (صفحه‌ای از همین سایت)، `https://`، `mailto:` یا `tel:` شروع شود؛ هر چیز دیگری
(مثل `javascript:`) هنگام ذخیره رد می‌شود.

### برگشت به متن پیش‌فرض

بخشی که هیچ‌وقت ویرایش نشده، متنی را نشان می‌دهد که سایت با آن ساخته شده. هر بخش ویرایش‌شده دکمهٔ
«برگرداندن به متن پیش‌فرض» دارد.

## نقش‌ها

| دسترسی | مدیر کل | ویراستار | نویسنده |
| --- | :---: | :---: | :---: |
| نوشتن مقاله (پیش‌نویس) | ✓ | ✓ | ✓ (فقط مقاله‌های خودش) |
| انتشار، زمان‌بندی و حذف مقاله | ✓ | ✓ | — |
| ویرایش مقالهٔ دیگران | ✓ | ✓ | — |
| صفحه‌ها، متن‌ها و دکمه‌ها، موضوع‌ها | ✓ | ✓ | — |
| بارگذاری رسانه | ✓ | ✓ | ✓ |
| ویرایش و حذف رسانهٔ دیگران | ✓ | ✓ | — |
| درخواست‌ها و مشترکین | ✓ | ✓ | — |
| کاربران و گزارش تغییرات | ✓ | — | — |

- اولین مدیر کل از خط فرمان ساخته می‌شود: `npm run admin:create -- ایمیل "نام" "گذرواژه"`.
  بقیهٔ حساب‌ها از «کاربران و دسترسی».
- ثبت‌نام عمومی و بازیابی گذرواژه با ایمیل وجود ندارد. هر کاربر از «حساب من» گذرواژه‌اش را عوض می‌کند؛
  مدیر کل می‌تواند برای هر کاربر گذرواژهٔ تازه بگذارد.
- کاربر غیرفعال‌شده در **همان درخواست بعدی** بیرون می‌رود؛ لازم نیست کوکی‌اش منقضی شود.
- آخرین مدیر کل فعال نمی‌تواند نقش خودش را پایین بیاورد یا غیرفعال شود.

## رسانه

- قالب‌های پذیرفته: JPG، PNG، WebP، GIF، AVIF و PDF، حداکثر ۱۰ مگابایت. نوع فایل از **محتوای** آن
  تشخیص داده می‌شود، نه از نام یا ادعای مرورگر. SVG عمداً پذیرفته نمی‌شود (می‌تواند اسکریپت داشته باشد).
- تصویرها هنگام بارگذاری چرخش EXIF را اعمال می‌کنند، حداکثر به عرض ۲۴۰۰ پیکسل کوچک می‌شوند، به WebP
  تبدیل می‌شوند، و **اطلاعات EXIF از جمله مکان GPS پاک می‌شود**. روی سایت `next/image` هر تصویر را در
  اندازهٔ مناسب هر صفحه و به‌صورت AVIF/WebP می‌فرستد.
- فایل تکراری (همان بایت‌ها) دوباره ذخیره نمی‌شود.
- فایلی که در مقاله، صفحه یا متن‌های سایت استفاده شده حذف نمی‌شود؛ پنل می‌گوید کجا استفاده شده.
- فایل‌ها در Postgres نگه داشته می‌شوند (جدول `media`)، نه روی دیسک کانتینر — کانتینر با هر استقرار عوض
  می‌شود ولی حجم دیتابیس می‌ماند و پشتیبان‌گیری از دیتابیس رسانه‌ها را هم می‌گیرد. نشانی هر فایل
  `/media/<id>/<name>` است و یک سال کش می‌شود.

## مقاله‌ها

- **ذخیرهٔ خودکار** هر ۲۰ ثانیه، فقط برای پیش‌نویس. **Ctrl+S** ذخیره می‌کند.
- **تاریخچهٔ نسخه‌ها:** هر ذخیرهٔ دستی نسخهٔ قبلی را نگه می‌دارد (۵۰ نسخهٔ آخر). هر نسخه قابل دیدن و
  برگرداندن است؛ برگرداندن خودش هم برگشت‌پذیر است.
- **پیش‌نمایش کامل** آخرین نسخهٔ ذخیره‌شده را با همان رندرکنندهٔ صفحهٔ عمومی نشان می‌دهد (فقط برای کاربران پنل).
- نوار ابزار: تیتر، پررنگ، کج، پیوند، فهرست، نقل‌قول، نکته، جدول و **درج تصویر از کتابخانه**
  (به‌صورت `<Figure>` با ابعاد، تا صفحه هنگام بارگذاری جابه‌جا نشود).
- **سئو:** عنوان و توضیح با شمارندهٔ کاراکتر و پیش‌نمایش نتیجهٔ گوگل، تصویر Open Graph (اگر خالی باشد
  کاور، و اگر کاور نباشد تصویر خودکار)، نشانی canonical برای نوشته‌ای که اول جای دیگری منتشر شده، و
  گزینهٔ noindex. مقالهٔ noindex یا دارای canonical بیرونی در نقشهٔ سایت نمی‌آید.
- زمان انتشار به وقت مرورگر نویسنده وارد و به‌صورت لحظهٔ مطلق ذخیره می‌شود؛ منطقهٔ زمانی سرور (UTC) در آن
  دخالتی ندارد.

## توضیح فنی

- **متن‌های سایت:** `lib/cms/registry.ts` هر بخش را با فیلدها و متن پیش‌فرضش تعریف می‌کند. مقدار ذخیره‌شده
  در جدول `settings` با کلید `content:<بخش>` است. `lib/cms/normalize.ts` هنگام خواندن هر فیلد خراب یا
  ناموجود را با پیش‌فرض پر می‌کند و هنگام ذخیره سخت‌گیرانه اعتبارسنجی می‌کند. فرم ویرایش
  (`components/admin/content/SectionEditor.tsx`) از همان تعریف ساخته می‌شود.
- **افزودن یک متن تازه به سایت:** فیلد را در بخش مربوط در `registry.ts` اضافه کن (با پیش‌فرض)، و در کامپوننت
  با `await getSection('<بخش>')` بخوانش. فرم پنل خودکار ساخته می‌شود.
- **اعمال فوری:** ذخیره `revalidatePath('/', 'layout')` را صدا می‌زند، پس صفحه‌های ISR و حتی صفحه‌های کاملاً
  استاتیک در درخواست بعدی تازه می‌شوند.
- **دسترسی:** `lib/admin/permissions.ts` ماتریس نقش‌هاست. هر server action با `requirePermission()` و هر صفحهٔ
  پنل با `guard()` بررسی می‌شود؛ حساب در هر درخواست از دیتابیس خوانده می‌شود.
- **صفحه‌های آزاد** در گروه مسیر `app/(cms)` هستند، نه `app/(site)`، چون `(site)/loading.tsx` پاسخ را پیش از
  `notFound()` با وضعیت ۲۰۰ شروع می‌کند (OPEN-QUESTIONS §۱۶). این‌جا نشانی ناموجود ۴۰۴ واقعی می‌دهد.
- **گزارش تغییرات** در جدول `audit_logs`؛ هر تغییر از پنل یک سطر می‌نویسد.
- چیزهایی که هنوز در کد هستند: متن ایمیل‌های تراکنشی، پرامپت چت‌بات، تصویر متحرک هیرو، متن صفحهٔ مشاوره
  و خبرنامه، و موضوع‌های فرم تماس (سرور آن‌ها را بررسی می‌کند).
