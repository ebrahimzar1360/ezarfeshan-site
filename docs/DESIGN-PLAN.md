## ۰. مبنای این طرح

اسکیل `ui ux pro max` روی سیستم نصب نبود (جزئیات در [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md)). برای اینکه طراحی به سلیقهٔ عمومی سقوط نکند، مبنا را روی چیزی گذاشتم که **قابل اثبات** است: هویت بصری بازیابی‌شده از خودِ برندگاید.

فایل برندگاید متن‌باخته بود، اما **گرافیک صفحات سالم مانده بود**. ۱۱ تصویر PNG استخراج شد که ۷ تای آن‌ها صفحات کامل A4 برندگاید هستند — بدون متن، ولی با لی‌اوت، رنگ‌گذاری و المان‌های تزئینی دست‌نخورده. این‌ها در `brand-source/recovered-pages/` ذخیره شده‌اند.

## ۱. اصول طراحی

پنج اصل. هر تصمیم بصری باید به یکی از این‌ها برگردد، وگرنه حذف می‌شود.

**۱. سند، نه لندینگ.**
این سایت اقتدار محتوایی می‌فروشد. چیزی که اعتماد می‌سازد، ظاهرِ «مطالعه‌شدنی» است نه ظاهرِ «فروختنی». لحن بصری از جنس گزارش داخلی یک مشاور است: مویی، دقیق، کم‌حرف. هیچ کارت شناور با سایهٔ رنگی، هیچ گرادیانت، هیچ گلس‌مورفیسم.

**۲. تایپوگرافی کار می‌کند، نه تزئینات.**
سلسله‌مراتب فقط با اندازه، وزن و فضا ساخته می‌شود. جعبه و قاب و آیکون آخرین راه‌حل‌اند، نه اولین.

**۳. طلایی خرج نمی‌شود، سرمایه‌گذاری می‌شود.**
سقف ۵٪ سطح. طلایی هیچ‌وقت متن نیست (کنتراست روی استخوانی: ۲.۱:۱ — مردود). فقط نشانه، لبه، و سطح بزرگ.

**۴. جسارت فقط در یک نقطه.**
نشانهٔ طلایی تنها المانی است که اجازه دارد خودنمایی کند. بقیهٔ سایت باید به‌قدری آرام باشد که این یکی دیده شود.

**۵. RTL بومی است، نه ترجمه‌شده.**
هیچ `left` یا `right` در CSS. همه‌چیز با خصوصیات منطقی. طراحی از راست شروع می‌شود، بعد آینه نمی‌شود.

## ۲. توکن‌های رنگ

### تم روشن (پیش‌فرض)

```css
:root {
  /* پایه — دقیقاً از برندگاید */
  --ink:       #1A1A1A;
  --paper:     #F5F5F0;
  --gold:      #C8A84B;
  --forest:    #1A3D2B;
  --emerald:   #2D6A4F;

  /* خنثی‌ها — از ink با شفافیت، نه از خاکستری‌های تیلویند */
  --ink-90:  color-mix(in oklab, var(--ink) 90%, transparent);
  --ink-70:  color-mix(in oklab, var(--ink) 70%, transparent);
  --ink-55:  color-mix(in oklab, var(--ink) 55%, transparent);
  --ink-30:  color-mix(in oklab, var(--ink) 30%, transparent);
  --ink-12:  color-mix(in oklab, var(--ink) 12%, transparent);
  --ink-06:  color-mix(in oklab, var(--ink)  6%, transparent);

  /* نقش‌ها */
  --bg:            var(--paper);
  --bg-raised:     #FFFFFF;
  --bg-inverse:    var(--forest);
  --text:          var(--ink);
  --text-muted:    var(--ink-70);
  --text-subtle:   var(--ink-55);
  --border:        var(--ink-12);
  --border-strong: var(--ink-30);
  --link:          var(--emerald);
  --link-hover:    var(--forest);
  --accent:        var(--gold);
  --focus:         var(--emerald);
}
```

### تم تیره

بر پایهٔ `--ink` و `--forest` طبق پرامپت. `--ink` خالص برای زمینه کمی تخت است، پس با یک اشارهٔ سبز عمیق‌ترش می‌کنم تا با `--forest` یک خانواده بماند. 🔹

```css
:root[data-theme="dark"] {
  --bg:            #141613;   /* ink با پرتوی سبز — هم‌خانواده با forest */
  --bg-raised:     #1C1F1C;
  --bg-inverse:    var(--forest);
  --text:          #EDEDE8;   /* paper کمی کم‌نورتر — کاهش هالهٔ نوری */
  --text-muted:    color-mix(in oklab, #EDEDE8 72%, transparent);
  --text-subtle:   color-mix(in oklab, #EDEDE8 55%, transparent);
  --border:        color-mix(in oklab, #EDEDE8 14%, transparent);
  --border-strong: color-mix(in oklab, #EDEDE8 28%, transparent);
  --link:          #5FA88A;   /* emerald روشن‌شده — emerald اصلی روی تیره مردود است */
  --link-hover:    #7DBFA2;
  --accent:        var(--gold);
  --focus:         #5FA88A;
}
```

### جدول کنتراست — محاسبه‌شده، نه حدسی

| ترکیب | نسبت | AA متن عادی | حکم |
|---|---:|:---:|---|
| `ink` روی `paper` | **۱۵.۹:۱** | ✅ | متن اصلی |
| `emerald` روی `paper` | **۵.۸:۱** | ✅ | لینک — قبول |
| `paper` روی `forest` | **۱۱.۰:۱** | ✅ | متن روی سکشن تیره |
| `gold` روی `forest` | **۵.۲:۱** | ✅ | متن تأکیدی روی تیره — قبول |
| `gold` روی `ink` | **۷.۶:۱** | ✅ | قبول |
| `gold` روی `paper` | **۲.۱:۱** | ❌ | **ممنوع برای متن.** فقط سطح و نشانه |
| `emerald` روی تیرهٔ `#141613` | **۲.۸۵:۱** | ❌ | به همین دلیل `#5FA88A` جایگزین شد |
| `#5FA88A` روی `#141613` | **۶.۴۶:۱** | ✅ | لینک دارک‌مود |
| `#EDEDE8` روی `#141613` | **۱۵.۵:۱** | ✅ | متن دارک‌مود |

**قانون سخت:** طلایی هرگز به‌عنوان `color` روی زمینهٔ روشن نمی‌آید. نه لینک، نه تیتر، نه عدد آماری.

## ۳. تایپوگرافی

**فارسی:** Vazirmatn ۴۰۰/۵۰۰/۷۰۰ — self-hosted، ساب‌ست‌شده، `font-display: swap`.
**لاتین و برچسب UI:** Inter (این یکی از فایل خراب سالم بیرون آمد).
**اعداد:** فارسی در متن روایی، لاتین در داده، کد، تاریخ ISO و شمارنده‌ها.

### مقیاس — نسبت ۱.۲۵ (سوم بزرگ)

```css
--fs-200:  0.8rem;     /* 12.8  — برچسب ریز، eyebrow */
--fs-300:  1rem;       /* 16    — پایهٔ UI، متادیتا */
--fs-400:  1.125rem;   /* 18    — متن مقاله (خارج از نسبت، عمدی) */
--fs-500:  1.25rem;    /* 20    — پاراگراف لید */
--fs-600:  1.5625rem;  /* 25    — h3 */
--fs-700:  1.953rem;   /* 31.25 — h2 */
--fs-800:  2.441rem;   /* 39    — h1 */
--fs-900:  3.052rem;   /* 48.8  — هیرو دسکتاپ */
--fs-1000: 3.815rem;   /* 61    — هیرو XL */
```

⚠ `--fs-400` تنها توکنی است که روی نسبت ننشسته. دلیلش صریح است: کف خوانایی متن مقاله ۱۸px است (الزام بخش ۴ پرامپت) و ۱۶ یا ۲۰ هیچ‌کدام درست نیستند. این استثنا مستند است، نه فراموش‌شده.

هیرو با `clamp()` سیال می‌شود: `clamp(var(--fs-800), 6vw, var(--fs-1000))`.

### ارتفاع خط — فارسی جای بیشتری می‌خواهد

```css
--lh-tight:  1.35;  /* هیرو و h1 */
--lh-snug:   1.5;   /* h2, h3 */
--lh-normal: 1.7;   /* UI */
--lh-prose:  1.9;   /* متن مقاله — دنباله‌های فارسی به این فضا نیاز دارند */
```

### طول سطر

`--measure: 38rem` (~۶۰۸px) → با Vazirmatn در ۱۸px حدود ۶۸ کاراکتر. در پاس نقد بصری (فاز ۸) با شمارش واقعی کالیبره می‌شود.

### وزن‌ها

`700` تیتر · `500` برچسب و دکمه · `400` متن. **هیچ وزن دیگری.** بدون italic — فارسی italic ندارد؛ تأکید با وزن یا رنگ.

## ۴. فاصله و شبکه

```css
--sp-1: 0.25rem;  --sp-2: 0.5rem;   --sp-3: 0.75rem;  --sp-4: 1rem;
--sp-6: 1.5rem;   --sp-8: 2rem;     --sp-12: 3rem;    --sp-16: 4rem;
--sp-24: 6rem;    --sp-32: 8rem;    --sp-40: 10rem;
```

**ریتم عمودی سکشن‌ها:** موبایل `--sp-16`، دسکتاپ `--sp-32`. سکشن‌های تیره یک پله بیشتر می‌گیرند تا وزنشان حس شود.

**شبکه:** ۱۲ ستونه، `max-width: 76rem` (۱۲۱۶px)، ناودان `--sp-6`.
حاشیهٔ کناری: `clamp(1.25rem, 5vw, 4rem)` — از الگوی ۶ (حاشیهٔ ۷٪) درآمده.

**شعاع و سایه:**

```css
--radius-sm: 4px;  --radius-md: 6px;  --radius-lg: 10px;
--shadow: 0 1px 2px var(--ink-06), 0 8px 24px var(--ink-06);
```

حداکثر شعاع ۱۰px. **هیچ `border-radius: 999px`** — دکمهٔ قرصی‌شکل جزو ضدالگوهای پرامپت است.
سایه فقط برای لایهٔ شناور (`Dialog`, `Toast`). کارت‌ها سایه ندارند؛ با `--border` از زمینه جدا می‌شوند (الگوی ۴).

## ۶. المان امضا — «نشانهٔ طلایی»

این تنها جایی است که طبق اصل ۴ جسارت خرج می‌شود.

### منشأ

در برندگاید، هر بند عنوان یک **میلهٔ عمودی طلایی در لبهٔ آغازین (راست)** دارد. در `img01` و `img04` تکرار شده. این المان اختراع من نیست — امضای موجود برند است.

### سه تجلی

**الف) نشانهٔ سکشن (ثابت)**

هر تیتر سکشن یک میلهٔ طلایی ۴px در `inset-inline-start` می‌گیرد.

```css
.section-head {
  padding-inline-start: var(--sp-4);
  border-inline-start: 4px solid var(--accent);
}
```

**ب) نوار پیشرفت مطالعه (پویا) — قلب ماجرا**

نوار پیشرفت افقی بالای صفحه یک کلیشه است. به‌جایش: **همان میلهٔ طلایی، در لبهٔ آغازین ستون متن مقاله، از بالا به پایین پر می‌شود.**

- ریل: `--ink-12`، عرض ۳px، در `inset-inline-start` ستون متن
- پرشونده: `--gold`، با `scaleY` و `transform-origin: top`
- پیاده‌سازی با CSS خالص: `animation-timeline: scroll()` — **صفر جاوااسکریپت**
- فالبک برای مرورگرهای قدیمی: نوار ساده و ثابت می‌ماند، محتوا آسیب نمی‌بیند

چرا خوب است: کاربر ناخودآگاه یاد می‌گیرد «طلایی یعنی جای مهم». همان چیزی که در سند چاپی می‌دید، اینجا زنده شده. یک المان، دو کار.

**ج) لحظهٔ ورود هیرو (یک‌بار، ارکستره)**

تنها انیمیشن نمایشی کل سایت:

| مرحله | زمان | حرکت |
|---|---|---|
| ۱ | `0ms` | میلهٔ طلایی از بالا به پایین کشیده می‌شود — `scaleY 0→1` روی `420ms` |
| ۲ | `180ms` | تگ‌لاین «سیستم بساز، آزاد باش» — `240ms` محو + ۸px بالا |
| ۳ | `300ms` | جملهٔ توضیحی — `200ms` |
| ۴ | `380ms` | دو CTA — `160ms` |

کل ماجرا زیر ۵۵۰ms. **فقط یک بار، فقط در هیرو.**
با `prefers-reduced-motion: reduce` کل توالی **حذف** می‌شود و همه‌چیز از ابتدا حاضر است — نه اینکه سریع‌تر شود.

### بقیهٔ حرکت‌ها

هرچه غیر از موارد بالا: زیر ۲۰۰ms، فقط `opacity` و `transform` و `border-color`. بدون کتابخانهٔ انیمیشن.

```css
--ease: cubic-bezier(0.22, 1, 0.36, 1);
--dur-fast: 120ms;  --dur-base: 180ms;  --dur-slow: 420ms;
```

## ۷. صفحهٔ اصلی — چیدمان بلوک‌ها

### ۱. هیرو — استخوانی

**نه** استک وسط‌چین. چیدمان نامتقارن و تایپ‌محور:

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│                        سیستم بساز، آزاد باش  ▐       │  ← fs-900/1000، وزن ۷۰۰
│                                              ▐       │     ▐ = نشانهٔ طلایی
│      برای مدیرانی که کسب‌وکارشان بدون خودشان         │  ← fs-500، ink-70
│      از حرکت می‌ایستد.                               │     حداکثر ۲ سطر
│                                                      │
│                   [ آخرین مقالات ]  عضویت در خبرنامه │  ← اولی پر، دومی متنی
└──────────────────────────────────────────────────────┘
```

- تگ‌لاین به‌عنوان **تز صفحه** رفتار می‌کند، نه شعار تزئینی
- ارتفاع `min-height: 72vh` — نه `100vh`. اسکرول باید پیدا باشد
- **بدون تصویر پس‌زمینه، بدون گرادیانت، بدون الگوی هندسی**
- CTA دوم متنی است با زیرخط ظریف — سلسله‌مراتب CTA پرامپت را می‌سازد

### ۲. تشخیص — تیرهٔ `--forest` تمام‌بلید

قوی‌ترین بلوک صفحه. اولین سکشن تیره است و ضربه‌اش را می‌زند.

چهار نقل‌قول درد، هرکدام روی خط مویی `--emerald` کم‌شفافیت، با `--fs-500`:

> «وقت ندارم برای این کارها.»
> «هوش مصنوعی فقط برای شرکت‌های بزرگ است.»
> «بارها نیروی کلیدی را از دست داده‌ام و از صفر شروع کرده‌ام.»
> «اگر فردا مریض شوید، کسب‌وکارتان چه می‌شود؟»

بعد الگو **می‌شکند** — پاسخ برند در `--fs-700` وزن ۷۰۰، بدون گیومه، با نشانهٔ طلایی:

**مشکل از آدم‌ها نیست. مشکل از سیستم است.**

این تنها جایی است که طلایی به‌عنوان متن می‌آید (روی forest: ۵.۲:۱ — مجاز).

### ۳. مقالات اخیر — استخوانی

قلب سایت. ۴ مقاله، **نه سه کارت مساوی آیکون‌دار** (ضدالگوی صریح پرامپت):

- مقالهٔ اول شاخص: عرض کامل، با تصویر کاور، تیتر در `--fs-600`
- سه تای بعدی: فهرست عمودی بدون تصویر — تیتر + خلاصه + زمان مطالعه + موضوع
- جداکننده: خط مویی `--border`، بدون قاب کارت

فهرست خواندنی‌تر از کارت است و به اصل ۱ وفادار.

### ۴. دربارهٔ من — استخوانی، دوستونهٔ نامتقارن

پرتره (۵ ستون) + روایت کوتاه «از میدان تا آینده» (۷ ستون). لینک متنی به `/about`.
⚠ تا رسیدن عکس واقعی، قاب `EmptyState` رندر می‌شود. **هیچ عکس استوکی.**

### ۵. منبع رایگان — `--bg-raised` روی استخوانی

یک منبع شاخص. فرم ایمیل تک‌فیلده، درون‌خطی، با هانی‌پات.
عنوان منبع + سه خط از محتوایش + دکمهٔ دریافت.

### ۶. اعتمادسازی — ساخته نمی‌شود

## ۸. صفحهٔ مقاله

```
        ┌─── ستون متن (38rem) ───┐   ┌── TOC ──┐
   ▐    عنوان (fs-800)                 چسبان

   ▐    ─────────────────────          با اسکرول
   ▐    ۱۲ دقیقه · ۳۰ مرداد ۱۴۰۴
   ▐
   ▐    متن (fs-400 / lh 1.9)
   ▐    ...
   ▐    ┌─ فرم خبرنامه (۶۰٪) ─┐
   ▐    ...
   ▲ نوار پیشرفت طلایی
```

- **نوار پیشرفت طلایی** در لبهٔ آغازین ستون متن (المان امضا، بخش ۶-ب)
- **TOC چسبان** فقط در `lg+`؛ زیر آن به یک `<details>` جمع‌شونده بالای متن تبدیل می‌شود
- بلوک نویسنده، خبرنامهٔ درون‌متنی بعد از ۶۰٪، مقالات مرتبط، اشتراک‌گذاری (کپی + واتساپ + تلگرام + لینکدین)

- `KeyNumber` تنها جایی است که عدد بزرگ نمایش داده می‌شود — و فقط با عدد واقعی

## ۱۱٫۵. لوگو

**انتخاب: طرح دایره‌ای.** بازترسیم‌شده به SVG وکتور — جزئیات کامل و تعارض رنگی که رفع شد در [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md).

همهٔ فایل‌ها در `public/brand/`:

| فایل | کاربرد |
|---|---|
| `logo-mark.svg` | نشان تنها — بخش تیره `currentColor` |
| `logo-lockup.svg` | افقی، برای هدر |
| `logo-stacked.svg` | عمودی، برای فوتر و OG |
| `favicon.svg` · `favicon-small.svg` · `icon-maskable.svg` | آیکون‌ها |

**نکتهٔ سریف:** نشان از Playfair Display (سریف پرکنتراست) ساخته شده، در حالی که اصل ۱ می‌گوید فونت سریف نداریم. این تعارض نیست: آن قانون دربارهٔ **تایپوگرافی رابط و متن** است. نشان لوگو یک شکل ترسیم‌شده است، نه فونت — و کنتراست سریفِ نشان با سنسِ رابط، تمایز مطلوبی می‌سازد.

**`currentColor` به‌جای دو فایل روشن/تیره:** بخش مشکی نشان رنگ را از `color` والد ارث می‌برد، پس با `--text` هر تم خودکار هماهنگ می‌شود. طلایی ثابت می‌ماند چون در هر دو تم AA پاس می‌کند (روی روشن فقط به‌عنوان سطح، نه متن).
