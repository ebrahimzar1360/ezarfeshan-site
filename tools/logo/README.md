# ساخت لوگو

```
npm run logo
```

خروجی:
- `public/brand/*.svg` — نشان، لاک‌آپ افقی و عمودی، فاویکون‌ها
- `components/ui/logo-mark.generated.ts` — همان نشان‌ها به‌صورت رشتهٔ inline برای هدر

`playfair700.ttf` و `inter600.ttf` ساب‌ست لاتین از Google Fonts (هر دو SIL OFL) و
فقط ورودی ساخت‌اند — در باندل سایت نمی‌روند.

**هرگز مسیرها را دستی داخل کامپوننت کپی نکن.** `glyph2path.js` مختصات را در فضای
em ۱۰۰۰ نرمال می‌کند و ترنسفورم‌ها به همان وابسته‌اند؛ کپی دستی یک بار باعث شد
حروف با یک‌دهم اندازه رندر شوند.
